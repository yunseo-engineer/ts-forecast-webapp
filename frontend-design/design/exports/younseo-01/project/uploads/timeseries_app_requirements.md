# 시계열 분석 웹앱 — 기획 요구사항서

> 작성일: 2026-04-25  
> 목적: 시계열 데이터 분석 SPA(Single Page Application) 개발 의뢰  
> 독자: 프론트엔드 / 풀스택 개발 담당자

---

## 1. 프로젝트 개요

사용자가 CSV 등 시계열 데이터 파일을 업로드하면, 자동으로 전처리·분석·예측을 수행하고 결과 대시보드를 시각화해주는 웹 애플리케이션이다.  
전체 흐름은 **랜딩 → 업로드/설정 → 분석 대시보드** 3단계로 구성된다.

---

## 2. 페이지 구조 및 흐름

```
[랜딩 페이지]
    │
    │  "시작하기" 버튼 클릭
    ▼
[업로드 & 분석 설정 페이지]
    │
    │  "분석하기" 버튼 클릭
    ▼
[결과 대시보드 페이지]
```

---

## 3. 디자인 방향

### 3-1. 핵심 키워드
- **Fancy / Luxury / Futuristic**
- 그라데이션, Glassmorphism(글래스 효과), 3D 요소 적극 활용
- 다크 베이스 + 컬러 그라데이션 포인트 권장
- 랜딩 페이지에서 **시계열 분석 툴**이라는 정체성이 시각적으로 명확히 드러나야 함 (예: 파형/차트 모티프, 데이터 시각화 요소)

### 3-2. 컬러 & 테마 (예시, 변경 가능)
| 역할 | 방향 |
|---|---|
| 베이스 | 딥 다크 네이비 / 블랙 계열 |
| 포인트 그라데이션 | 퍼플 → 시안 → 블루 (또는 유사 계열) |
| 글래스 카드 | `backdrop-filter: blur`, 반투명 테두리 |
| 텍스트 | 흰색 계열, 강조는 그라데이션 텍스트 |

### 3-3. 폰트
- 제목: 개성 있는 디스플레이 폰트 (예: Space Grotesk, Outfit, Syne 등)
- 본문: 가독성 중심 sans-serif
- 데이터/수치: 모노스페이스

## 4. 애니메이션 요구사항

### 4-1. 마우스 인터랙션
- **마우스 이동에 따라 배경 또는 오브젝트가 반응**해야 함
  - 예: 배경 그라데이션이 마우스 위치 따라 흐름 / 파티클이 커서를 향해 이동 / 3D 카드가 마우스 방향으로 기울어짐 (CSS perspective + transform)

### 4-2. 랜딩 페이지 스크롤 애니메이션
- 히어로 섹션에 **시계열 차트 형태의 이모지 또는 아이콘 오브젝트**가 존재하고, 스크롤 다운 시 해당 오브젝트가 **함께 따라 내려오는(parallax) 효과**를 가져야 함
- 스크롤에 따라 콘텐츠 섹션이 순차적으로 **fade-in / slide-up** 등으로 등장

### 4-3. 페이지 진입 애니메이션
- 랜딩 페이지 최초 로드 시: 헤드라인, 서브텍스트, CTA 버튼이 **staggered(순차) 애니메이션**으로 등장
- 페이지 전환 시 부드러운 transition 처리

## 5. 각 페이지 상세 명세

---

### 5-1. 랜딩 페이지 (Landing Page)

#### 네비게이션 바
- 좌측: 서비스 로고/이름 (현재 ForecastLab)
- 우측: 시계열 기초 지식 메뉴 항목들 (항목명은 미정, 예시는 아래 참고)
  - 시계열 데이터란 / 시계열 예측 과정 (데이터 콜렉션 - 전처리 - pattern learning - forecasting - decision making) 
  - 클릭 시 해당 내용 페이지 또는 모달/슬라이드인 패널로 표시
- 스크롤 시 네비게이션 바 `backdrop-filter` 적용하여 글래스 효과

#### 히어로 섹션 (최상단 화면)
- **대형 헤드라인**: 서비스 핵심 가치 전달 (예: "시계열 데이터를 인사이트로")
- **서브 텍스트**: 1~2줄 설명 (간결하게)
- **CTA 버튼**: "시작하기" → 업로드 페이지로 이동
- **시각적 요소**: 시계열 차트 형태의 애니메이션 또는 3D 오브젝트
  - 마우스 이동에 반응하는 인터랙티브 요소 포함
  - 스크롤 시 이 오브젝트가 화면과 함께 **parallax**로 내려오는 효과

#### 스크롤 섹션 1 — 시계열 분석 개요 (1~2 화면 분량)
- 시계열 분석이 무엇인지, 어떤 문제를 해결하는지 소개
- 텍스트 + 간단한 다이어그램 또는 인포그래픽 조합
- 스크롤 트리거 등장 애니메이션 적용

#### 스크롤 섹션 2 — 전처리 과정 개요
- 데이터가 어떻게 전처리되는지 흐름 소개
  - 예: 원시 데이터 → 결측치 처리 → 정상성 변환 → 모델 입력
- 플로우차트 또는 스텝 카드 형태 시각화
- 스크롤 트리거 등장 애니메이션 적용

#### 기능 소개 섹션 (선택)
- 핵심 기능 3~4개를 글래스 카드로 배치

---

### 5-2. 업로드 & 분석 설정 페이지 (Upload Page)

#### 파일 드롭 존
- 드래그 앤 드롭 + 클릭 업로드 모두 지원
- 지원 형식 표시: CSV
- 업로드 완료 시 인라인 피드백 표시 (파일명, 행/열 수 등)

#### 분석 설정
| 설정 항목 | 설명 |
|---|---|
| 날짜/시간 컬럼 | 자동 감지 또는 사용자 선택 |
| 데이터 주기 | 자동 감지 / 일별 / 주별 / 월별 등 |
| 목표 컬럼 | 예측할 수치 컬럼 선택 |
| 예측 기간 | 입력할 수 있게 |
| 시평 | 파라미터로 변경이 가능해야함 
| 수요와 파일이 변경되면, 새로운 예측을 수립할 수 있어야 함| 

#### 액션
- **"분석하기" 버튼**: 클릭 시 대시보드 페이지로 이동 (로딩 상태 표시 포함)

---

### 5-3. 분석 결과 대시보드 (Dashboard Page)

#### 상단 요약
- 자동 진단 결과 배지 표시
  - 정상성 검정 결과 (ADF p-value 등)
  - 계절성 감지 여부
  - 이상치 건수
  - 추천 모델명

#### 주요 차트 (우선순위 순)

| 순서 | 차트 | 설명 |
|---|---|---|
| 1 | 시계열 플롯 + 예측 구간 | 실제값 + 예측값 + 신뢰구간 표시 |
| 2 | 시계열 분해 | 트렌드 / 계절성 / 잔차 3개 서브 플롯 |
| 3 | ACF / PACF | 자기상관 막대 차트 |
| 4 | 모델 성능 비교 | AIC, MAPE, RMSE 기준 모델 순위 표 |
 다양한 평가지표에 대한 시각화 대시보드를 통하여 현재 예측이 적절한지 판단할 수 있어야 함 

#### 부가 기능
- 리포트 PDF 내보내기 버튼
- 예측값 CSV 내보내기 버튼

01 · 시계열이란

시간이 만든 패턴은 미래를 말한다.

시계열(Time-series)은 시간 순서대로 관측된 데이터입니다. 매출, 트래픽, 센서 신호 — 시간 축 위의 모든 점은 자기상관을 가지며, 그 안에는 추세 · 계절성 · 잔차 세 겹의 이야기가 숨어 있습니다.

TREND
장기 방향성
SEASONAL
반복 주기
RESIDUAL
설명되지 않는 잔차

03 · 모델 종류

4 가지 예측 엔진이 동시에 달립니다.

통계 기반의 정직한 베이스라인부터 비선형을 다루는 딥러닝까지 — 데이터가 들어오면 모두 동시에 학습되고, 가장 성능이 좋은 모델이 선택됩니다.

STATISTICAL

ARIMA / SARIMA

자기회귀(AR) + 차분(I) + 이동평균(MA). 정상성 가정 하에 안정적인 통계적 베이스라인. 계절성을 추가한 SARIMA 까지.

· 짧은 시계열에 강함 · 해석 가능
DECOMPOSITION

Prophet

Meta가 만든 분해 기반 모델. 추세 변화점, 휴일 효과, 강한 계절성을 자동으로 처리. 결측에도 강건합니다.

· 휴일 자동 · 변화점 탐지
SMOOTHING

ETS

지수평활(Exponential Smoothing). 최근 값에 더 큰 가중치. 짧은 시계열, 부드러운 추세, 곱셈형 계절성에 효과적.

· 빠름 · 적은 데이터 OK
DEEP LEARNING

LSTM / Transformer

순환 신경망과 어텐션 기반 모델. 비선형 패턴, 다변량 입력, 장기 의존성에 유리. 데이터가 충분할 때 최고의 정확도.

· 비선형 · 다변량 입력
04 · 평가지표

예측의 진실은 숫자로 검증됩니다.

하나의 숫자만 믿으면 함정에 빠집니다. ForecastLab은 4가지 지표를 동시에 보여주고, 각 지표가 무엇을 강조하는지 설명합니다.

|y − ŷ| / y × 100 / n
MAPE
Mean Absolute Percentage Error

퍼센트 단위라 직관적. 단, 실제값이 0 근처면 폭발하는 약점이 있습니다.

직관성★★★★☆
√Σ(y − ŷ)² / n
RMSE
Root Mean Squared Error

큰 오차에 패널티가 큽니다. 원본 데이터와 단위가 같아 비교가 쉽습니다.

이상치 민감★★★★★
Σ|y − ŷ| / n
MAE
Mean Absolute Error

이상치에 강건. 모든 오차를 동등하게 취급하므로 robust한 평가가 필요할 때.

강건성★★★★★
−2 ln L + 2k
AIC / BIC
Information Criterion

모델의 복잡도(파라미터 수)를 패널티로 부과. 과적합을 막는 모델 선택 기준.

모델 선택★★★★☆
